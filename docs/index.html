solana-launchpad-ui

A static UI template for a Solana token launchpad in the style of pump.fun: a token board, a create form, a token page with a trade panel, and a profile. Plain HTML, CSS and ES modules with no build step and no dependencies.

Mock data only. Nothing in the template connects to a wallet, an RPC node or a blockchain, and it is not affiliated with pump.fun. Every token, price, trade and profile is invented.

Run it locally

The pages load ES modules, which browsers refuse over file://, so serve the folder over HTTP.

npx serve .

Or, with Python: python3 -m http.server 8000, then open http://localhost:8000.

To run the checks (Node 20 or later, nothing to install):

npm run check && npm test

Bonding curve

curve.js implements the constant-product curve the template illustrates.

  • Virtual reserves start at 30 SOL and 1,073,000,000 tokens; 793,100,000 tokens are sold through the curve out of a 1,000,000,000 supply with 6 decimals.
  • A buy that adds net lamports after the 1% fee returns tokensOut = vT - k / (vS + net), where k = vS × vT.
  • Amounts are BigInt base units and divisions round in the pool's favour. Buys past the end of the curve are capped at the remaining tokens.
  • Completing the curve takes about 85 SOL of deposits; the market cap runs from about 28 SOL at launch to about 411 SOL at completion.

It illustrates the formula and is not a client for any deployed program. test/curve.test.js checks it against independently computed values.

Customise

  • Colours: the custom properties in styles.css :root. The text tokens are chosen to pass WCAG AA contrast on every background token; keep them that way.
  • Data: mock-data.js holds the tokens, creators, the featured token's curve progress and the fixed MOCK_SOL_USD rate. Replace it with a real source when you wire up a backend.
  • Static figures: the featured token's price, market cap and trades are also written into token.html and index.html for readers without JavaScript. test/figures.test.js fails if they no longer match the curve.
  • Security headers: vercel.json sets a Content-Security-Policy that allows scripts only from the site itself. Keep scripts in files and markup free of inline handlers and style attributes.
